# 校园失物招领 APP

基于 HTML5 + CSS3 + 原生 JavaScript 开发的移动端 Web APP，并通过 HBuilderX 打包为 Android APK。该项目为《构建之法》结对编程作业，旨在解决校园内失物信息分散、查找困难的问题。

## 一、目录结构说明

- `index.html`：主页面（包含首页、发布、搜索、详情四个视图）
- `test.html`：单元测试页面
- `manifest.json`：HBuilderX 打包配置文件
- `css/style.css`：全局样式表
- `js/script.js`：核心逻辑（数据层、页面切换、搜索、发布、状态更新）
- `README.md`：项目说明文档

HTML 采用单页面多视图方式，切换时通过 JavaScript 控制显示隐藏；CSS 统一管理样式，实现移动端界面的清爽布局；JS 封装了 localStorage 数据层、搜索逻辑、发布逻辑和状态更新逻辑，职责分明。

## 二、如何使用

### 1. 网页测试（推荐在电脑上评估）
- 下载整个项目文件夹到本地；
- 双击打开 `index.html`；
- 使用谷歌浏览器（Chrome）打开，按 `F12` 切换到手机模式即可预览效果。

### 2. APP 测试（推荐在手机上评估）
- **注意**：本 APP 为安卓版本，仅支持安卓系统，苹果手机（iPhone）无法安装；
- 在仓库根目录下载 `.apk` 后缀的文件；
- 将 APK 文件传输到安卓手机（可通过微信文件传输助手或数据线）；
- 在手机上点击安装（需允许“安装未知来源应用”），推荐安卓 8.0 及以上系统；
- 若无安卓手机，可使用电脑上的安卓模拟器（如雷电模拟器、夜神模拟器）拖入 APK 安装运行。

## 三、核心功能

1. **浏览信息**：首页按“全部/寻物/招领”分类查看校园失物招领内容；
2. **发布信息**：选择寻物或招领，填写物品名称、地点、联系方式并发布；
3. **搜索物品**：支持按物品名称模糊搜索，无结果时有友好提示；
4. **查看详情**：展示完整信息，支持一键复制发布者联系方式；
5. **状态维护**：发布者可在详情页将信息标记为“已找到/已归还”，首页卡片同步更新状态。

## 四、附加特点

- **一键复制联系方式**：无需手动记录，点击按钮即可复制到剪贴板；
- **分类筛选与空状态提示**：提供分类 Tab 快速定位，搜索无结果时展示提示，避免白屏。
